# CService
CService, Cevahir Turizm için oluşturulmuş modern bir puantaj uygulamasıdır.

## Teknolojiler
- ASP.NET Core MVC 8 (.NET 8)

## Proje Yapısı
```
CService.sln
src/
  CService.Web/   # ASP.NET Core MVC web uygulaması
```

## Geliştirme Ortamını Hazırlama
```bash
dotnet restore
dotnet build
```

## Uygulamayı Çalıştırma
```bash
dotnet run --project src/CService.Web
```
